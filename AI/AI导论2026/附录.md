## 附录

### A. 核心术语表

本术语表收录全书涉及的核心技术术语，按字母排序。

**Agent（智能体）** ：能够感知环境、自主决策和执行行动的自治系统。本书特指基于LLM的工具调用Agent，核心公式为：**Agent = Model + Scaffolding + Harness**。在更简化的日常讨论中，常表述为 **Agent = Model + Harness**。Agent的本质是“能在环境中采取行动、观察结果、并据此决定下一步行动的LLM系统”。

**Agent Loop（智能体循环）** ：Agent交替进行“推理-行动-观察”的运行机制，源自ReAct范式。模型不再一次性给出最终答案，而是循环执行：思考 → 选择工具 → 执行 → 观察结果 → 再思考 → … → 达成目标。

**Context Engineering（上下文工程）** ：动态管理Agent每一步所“看到”的内容——系统提示词、工具描述、对话历史、检索到的知识。它决定了“Agent看什么”，是Scaffolding的核心组成部分。

**Diffusion Model（扩散模型）** ：通过学习“逆向去噪”过程来生成数据的生成模型。前向过程逐步将图像加噪至纯噪声，反向过程学习从噪声中逐步恢复图像。2026年，主流高质量生成模型已从UNet转向DiT（Diffusion Transformer）架构。

**DPO（Direct Preference Optimization，直接偏好优化）** ：2024-2026年迅速普及的轻量级偏好对齐方案，绕开了RLHF所需的奖励模型和强化学习，直接将“好回答”与“坏回答”的对比转化为二分类损失函数。

**Embedding（嵌入）** ：将离散对象（词、图像、文档）映射到连续向量空间的过程。向量在空间中的距离反映了语义相似度。

**Harness（驾驭）** ：本书的核心概念。原指骑手驾驭烈马的缰绳和鞍具系统。在AI语境中，指包裹在大模型外围、将其推理能力转化为可靠可控生产级系统的完整工程基础设施。具体而言，Harness是驱动模型运行的执行控制层——调用模型、处理工具调用、判断何时停止。**Harness Engineering（驾驭工程）是2025-2026年AI Agent领域最重要的工程范式转移**。

**LLM（Large Language Model，大语言模型）** ：基于Transformer架构的大规模预训练语言模型。本质是一个概率性的文本生成器——输入文本，根据统计规律输出文本。模型本身没有跨调用记忆，也不会自己循环执行任务。

**LoRA（Low-Rank Adaptation）** ：一种参数高效的微调方法，通过注入低秩矩阵来近似全参数微调，大幅减少可训练参数量。

**MCP（Model Context Protocol）** ：模型上下文协议，一种标准化的工具调用和上下文交互协议。

**MoE（Mixture of Experts，专家混合）** ：一种模型架构，每一层包含多个“专家”子网络，推理时只激活其中表现最好的少数几个。2026年千亿级以上模型的主流选择。

**Multi-Head Attention（多头注意力）** ：Transformer的核心组件之一。用多组不同的投影矩阵并行计算注意力，然后将结果拼接，让模型从多个角度理解序列中的关系。

**Multimodal Model（多模态模型）** ：能同时处理多种数据类型（文本、图像、音频、视频）的AI模型。2026年的前沿方向是“原生多模态融合”——从预训练开始就将不同模态作为同等的token类型统一训练。

**PTC（Programmatic Tool Calling，程序化工具调用）** ：模型直接生成代码（如Python/TypeScript脚本）来编排多个工具的执行流程，而非仅输出单个函数调用。

**RAG（Retrieval-Augmented Generation，检索增强生成）** ：在生成回答前，先从知识库中检索相关文档片段，将检索结果作为上下文注入给LLM。解决LLM知识滞后和幻觉问题的核心范式。

**ReAct（Reasoning + Acting）** ：2022年Princeton和Google提出的Agent范式。模型交替进行推理和行动，在循环中逐步逼近目标。

**RLHF（Reinforcement Learning from Human Feedback，基于人类反馈的强化学习）** ：用人类偏好数据训练奖励模型，再通过强化学习（PPO算法）微调LLM，使其输出更符合人类期望。

**RoPE（Rotary Position Embedding，旋转位置编码）** ：2024年后几乎所有新模型采用的位置编码方案。在计算Q和K的点积时直接对向量进行“旋转”。

**Scaffolding（脚手架）** ：模型所“感知”的一切——系统提示词、工具描述、输出格式、上下文管理等。它塑造了模型的行为边界，但本身不负责运行。Scaffolding是模型可感知的部分，Harness是驱动模型运行的部分。

**Scaling Laws（规模法则）** ：模型性能随参数规模、数据量和算力呈幂律增长的规律。2024-2025年遭遇瓶颈后，催生了“推理时扩展”（Test-Time Scaling）的新方向。

**Self-Attention（自注意力）** ：Transformer的核心机制。通过Q（Query）、K（Key）、V（Value）三个向量，让序列中的每个位置都能直接“关注”所有其他位置。本质是让每个词的新表示成为所有词表示的加权组合。

**SFT（Supervised Fine-Tuning，有监督微调）** ：在预训练后用人工标注的“指令-回答”数据对模型进行监督学习，使其学会遵循指令和对话。

**Tool Use / Function Calling（工具调用/函数调用）** ：模型输出结构化指令（如JSON）来请求调用外部工具（API、数据库、代码执行等）。Harness负责解析请求、真正执行工具、将结果返回模型。

**Transformer**：2017年Google提出的序列建模架构，核心是自注意力机制。所有现代大语言模型和多模态模型的基础。

**World Model（世界模型）** ：能够在内部模拟物理世界运行规律的模型——预测物体运动、理解因果关系、推理物理常识。具身智能和自动驾驶的核心技术方向。

### D. 实践项目提案（从入门到进阶）

以下项目按难度分为四个层次，从“跑通Demo”到“构建生产级系统”。

#### 层次一：入门级（1-2周，熟悉基础工具链）

**项目1：文档问答助手（RAG from Scratch）**
- **目标**：构建一个能回答PDF/文档问题的聊天机器人
- **技术栈**：Python + LangChain/LlamaIndex + ChromaDB + 开源Embedding模型
- **核心步骤**：文档加载与分块 → 生成向量嵌入 → 存入向量数据库 → 构建检索链 → 接入LLM生成回答
- **学习收获**：理解RAG全流程、向量检索、上下文注入
- **参考资源**：`iam-veeramalla/RAG-crash-course`

**项目2：结构化输出分类器**
- **目标**：用LLM将非结构化文本转为结构化JSON输出
- **技术栈**：FastAPI + 任意LLM API
- **核心步骤**：定义输出Schema → 设计System Prompt → 搭建API服务 → 测试与优化
- **学习收获**：Prompt Engineering、结构化输出、API服务搭建

**项目3：会议纪要与待办提取器**
- **目标**：自动将会议录音/转录文本转为结构化纪要和待办事项
- **技术栈**：Whisper（语音转文字）+ LLM（总结与提取）
- **核心步骤**：音频转录 → 文本分段 → LLM提取讨论要点/决策/待办/负责人 → 输出Markdown
- **学习收获**：语音识别集成、信息抽取、输出格式化

#### 层次二：中级（2-4周，深入Agent与工具调用）

**项目4：个人知识库问答系统（RAG + Agent）**
- **目标**：构建支持多轮对话、能主动检索和引用的知识库助手
- **技术栈**：LangChain/LlamaIndex + 向量数据库 + Agent框架
- **核心步骤**：多源文档加载（PDF/Word/网页）→ 混合检索（向量+关键词）→ 重排序 → Agent化问答
- **学习收获**：高级RAG技术（HyDE、重排序）、Agent工具调用、可观测性

**项目5：社交媒体AI Agent（带审批流）**
- **目标**：自动生成社交媒体内容，经人工审批后发布
- **技术栈**：Agent框架 + 社交媒体API + 审批工作流
- **核心步骤**：内容生成Agent → 审批队列 → 人工审批界面 → 发布Agent
- **学习收获**：人机协同设计、审批流、Agent状态管理

**项目6：MCP文件系统服务器**
- **目标**：实现一个MCP协议的文件系统工具服务器
- **技术栈**：MCP SDK + Python/TypeScript
- **核心步骤**：实现MCP工具定义（读/写/列表/搜索）→ 部署为MCP Server → 接入任意Agent框架调用
- **学习收获**：MCP协议、工具标准化、Agent-工具集成

#### 层次三：高级（1-2个月，系统级Agent开发）

**项目7：自动化工作流Agent（多步骤任务编排）**
- **目标**：构建能自主规划和执行多步骤任务的Agent
- **技术栈**：DeepSeek Harness / LangGraph + 多种工具（浏览器、Shell、API）
- **核心步骤**：任务拆解（Plan-and-Solve）→ DAG执行引擎 → 错误恢复与重试 → 可观测性追踪
- **学习收获**：Agent Loop设计、任务规划、错误处理、Harness工程

**项目8：企业级RAG系统（生产部署）**
- **目标**：构建可扩展、可监控的企业知识库问答系统
- **技术栈**：FastAPI + 向量数据库（Milvus/Pinecone）+ 缓存 + 可观测性
- **核心步骤**：文档增量更新 → 权限控制 → 缓存策略 → 监控告警 → A/B测试
- **学习收获**：生产级部署、可扩展性、成本优化、评估体系

**项目9：多智能体协作系统**
- **目标**：构建多个Agent分工协作完成复杂任务
- **技术栈**：CrewAI / AutoGen / DeepSeek Harness多Agent插件
- **核心步骤**：定义Agent角色（研究员/分析师/撰写者）→ 设计通信协议 → 仲裁机制 → 结果聚合
- **学习收获**：多Agent协作、任务分配、冲突解决

#### 层次四：专家级（3个月+，前沿探索）

**项目10：自定义Harness框架**
- **目标**：从零构建一个轻量级Agent Harness
- **技术栈**：Python/TypeScript + 任意LLM API
- **核心步骤**：实现Agent Loop → 工具调用解析与执行 → 记忆管理 → 上下文压缩 → 可观测性追踪 → 插件化架构
- **学习收获**：深入理解Harness Engineering、系统设计

**项目11：本地Coding Agent**
- **目标**：构建全本地、隐私优先的编程助手
- **技术栈**：Ollama + Qwen/Llama + OpenHands
- **核心步骤**：本地模型部署 → 代码仓库理解 → 多文件编辑 → 测试运行与修复 → Git集成
- **学习收获**：Coding Agent架构、Sim2Real（代码世界的“Real”）

**项目12：具身智能仿真（Sim2Real）**
- **目标**：在仿真环境中训练一个机器人Agent并迁移到真实环境
- **技术栈**：NVIDIA Isaac Sim / MuJoCo + 强化学习 + Sim2Real迁移
- **核心步骤**：搭建仿真环境 → 训练策略 → 域随机化 → 迁移到真实机器人（或仿真中的“真实”测试）
- **学习收获**：具身智能、强化学习、Sim2Real
