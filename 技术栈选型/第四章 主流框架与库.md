# **第四章 主流框架与库**

选完语言之后，下一步就是选框架。语言是地基，框架是盖房子的预制件。用框架的好处是：别人已经帮你解决了大量常见问题，你不需要从零造轮子。比如做 Web 前端，React 帮你管理界面状态和组件复用；做后端，FastAPI 帮你处理路由、参数校验、文档生成；做移动端，Flutter 帮你一套代码跑两个平台。框架选对了，开发速度翻倍；选错了，你会觉得处处别扭，AI 也帮不上忙。

这一章会按前端、后端、移动端、桌面端、AI 应用五个方向，逐一介绍主流框架。每个框架我会说清楚它的特色、适合什么场景、生态怎么样、学习成本高不高、新手推不推荐。你不需要全部记住，但要知道每个框架大概是什么定位，遇到项目时能快速判断。

## **4.1 前端框架**

前端框架是负责浏览器界面的。用户看到的页面、点击的按钮、跳转的路由、加载的数据，都由前端框架管理。现代前端框架基本都是组件化、声明式、响应式的。你描述“界面应该长什么样”，框架负责在数据变化时高效更新 DOM。下面介绍几个主流选择。

### **React**

React 是 Facebook（现 Meta）2013 年开源的框架，目前全球最流行。它的核心思想是“组件化”和“声明式 UI”。你把页面拆成一个个组件，每个组件是一个函数，接收 props，返回 JSX（类似 HTML 的语法）。数据变化时，React 重新渲染组件，通过虚拟 DOM 计算最小更新。

React 最大的特点是灵活。它只负责 UI 层，路由、状态管理、数据请求都交给社区库。这种“不opinionated”的设计让 React 生态极其庞大，你可以自由组合。但灵活也是双刃剑：新手容易迷失在无数选择中，不知道该用哪个路由、哪个状态管理、哪个请求库。

React 的生态是前端框架中最大的。Next.js 是全栈框架，React Router 是路由，Redux、Zustand、Jotai 是状态管理，TanStack Query 是数据请求，Material UI、Ant Design、Chakra UI 是组件库，React Native 是移动端，React Three Fiber 是 3D。几乎任何需求，React 都有成熟方案。

学习成本方面，React 属于中等。JSX 语法、组件生命周期、Hooks（useState、useEffect、useContext、useMemo）需要时间理解。但一旦掌握，开发效率很高。新手推荐度是五星，因为生态大、教程多、AI 熟悉、就业机会多。

React 适合几乎所有的 Web 前端场景：官网、后台、SaaS、电商、社区、AI 应用前端。如果你不确定选什么，React 是最稳的默认选择。

### **Vue**

Vue 是尤雨溪 2014 年开源的框架，主打“渐进式”和“易上手”。它的核心是模板语法，你写类似 HTML 的模板，Vue 自动处理数据绑定和更新。Vue 的 API 设计友好，文档质量极高，中文资料丰富，在国内特别流行。

Vue 的特点是渐进式。你可以只用它增强一个静态页面，也可以用它构建完整单页应用。Vue 官方提供了路由（Vue Router）、状态管理（Pinia）、构建工具（Vite），生态虽然不如 React 大，但官方方案齐全，新手不容易迷路。

Vue 的生态在国内非常强。Element Plus、Ant Design Vue、Naive UI 是常用组件库，Nuxt 是全栈框架，Vite 是构建工具。很多国内公司、政府项目、后台系统都用 Vue。

学习成本方面，Vue 比 React 略低。模板语法接近 HTML，新手容易理解。响应式系统自动追踪依赖，不需要手动优化。新手推荐度是五星，尤其适合有 HTML / CSS 基础的人。

Vue 适合中小型 Web 应用、后台管理系统、企业官网、快速原型。如果你在国内，Vue 的社区支持和就业机会都很好。

### **Svelte**

Svelte 是 2016 年出现的框架，最大特点是“编译时框架”。React 和 Vue 在运行时做大量工作，Svelte 在编译时把代码转换成高效的原生 JavaScript。结果是：代码量少、性能好、包体积小。Svelte 没有虚拟 DOM，直接操作 DOM，运行效率高。

Svelte 的语法非常简洁。你写 `let count = 0`，模板里用 `{count}`，修改时直接 `count++`，Svelte 自动更新。不需要 useState、useEffect，代码量通常比 React 少一半。SvelteKit 是它的全栈框架，类似 Next.js。

Svelte 的生态相对小，但增长稳定。组件库、工具、教程不如 React / Vue 多，但核心需求都能满足。学习成本低，适合喜欢简洁的人。新手推荐度是四星，因为生态小一些，遇到问题可能资料少。

Svelte 适合小中型应用、追求性能和简洁的项目、个人项目。如果你厌倦了 React 的复杂度，Svelte 会让人耳目一新。

### **Angular**

Angular 是 Google 2016 年发布的框架，前身是 AngularJS。它是企业级全功能框架，自带路由、表单、HTTP、依赖注入、测试工具。Angular 用 TypeScript，强制结构化，适合大型团队协作。

Angular 的特点是“大而全”。你不需要选路由、选状态管理，Angular 都提供了。它的依赖注入、模块系统、RxJS 响应式编程，适合复杂企业应用。但学习曲线陡，概念多，代码量大，新手容易劝退。

Angular 的生态在企业领域很强。很多大公司、金融、政府项目用 Angular。但社区热度不如 React / Vue，新项目比例下降。学习成本高，新手推荐度三星。

Angular 适合大型企业应用、长期维护项目、团队协作。如果你进大公司做前端，可能会遇到 Angular。

### **Next.js**

Next.js 是基于 React 的全栈框架，由 Vercel 维护。它解决了 React 单页应用的几个痛点：SEO、首屏加载、路由、API。Next.js 支持服务端渲染（SSR）、静态生成（SSG）、增量静态再生（ISR）、API Routes、文件路由、图片优化、中间件。

Next.js 的核心优势是“全栈”。你可以在同一个项目里写前端页面和后端 API，部署到 Vercel 一键完成。App Router（Next.js 13+）引入 React Server Components，让服务端和客户端组件分离，性能和开发体验都提升。

Next.js 生态极大，是当前 React 全栈的事实标准。学习成本中等，需要理解 SSR、SSG、Server Components、路由约定。新手推荐度五星，尤其适合做 SaaS、官网、AI 应用、电商。

Next.js 适合需要 SEO、快速上线、全栈开发的项目。如果你用 React，Next.js 是最推荐的搭配。

### **Nuxt**

Nuxt 是基于 Vue 的全栈框架，对标 Next.js。它支持 SSR、SSG、文件路由、API Routes、自动导入、模块系统。Nuxt 3 基于 Vite，性能好，开发体验佳。如果你用 Vue，想做 SEO 或全栈，Nuxt 是首选。

Nuxt 的生态在 Vue 社区很强，模块丰富，文档好。学习成本中等，Vue 基础好的人上手快。新手推荐度四星。

Nuxt 适合 Vue 全栈项目、SEO 网站、内容平台。

### **前端框架选择建议**

如果你不确定，选 React + Next.js。这是生态最大、就业最广、AI 最友好的组合。如果你在国内、喜欢简单、做后台系统，选 Vue + Nuxt。如果你追求简洁和性能，选 Svelte + SvelteKit。如果你进大公司做企业应用，可能要学 Angular。

新手不要同时学多个前端框架。先精通一个，做出项目，再触类旁通。

## **4.2 后端框架**

后端框架负责处理请求、业务逻辑、数据库操作、鉴权、返回响应。它是 API 服务的核心。后端框架通常和语言绑定：Python 有 Django / Flask / FastAPI，Node.js 有 Express / NestJS，Java 有 Spring Boot，Go 有 Gin，PHP 有 Laravel，Ruby 有 Rails。下面逐一介绍。

### **Node.js / Express**

Node.js 是 JavaScript 运行时，让 JS 能写后端。Express 是 Node.js 最经典的 Web 框架，轻量、灵活、中间件生态大。你定义路由，写处理函数，返回 JSON。Express 不强制结构，适合小型 API、原型、实时应用。

Express 的学习成本低，JS 基础好的人一天能上手。生态极大，中间件覆盖鉴权、日志、CORS、限流、文件上传。但 Express 太灵活，大型项目容易混乱，需要自己约定结构。新手推荐度四星。

Express 适合小型 API、快速原型、实时应用、Serverless 函数。如果你用 Node.js 做后端，Express 是入门首选。

### **NestJS**

NestJS 是 Node.js 的企业级框架，用 TypeScript，借鉴 Angular 的架构。它有模块、控制器、服务、依赖注入、装饰器、管道、守卫、拦截器。NestJS 强制结构化，适合中大型项目、团队协作。

NestJS 的学习成本中等，概念多，但文档好。生态成熟，支持 GraphQL、WebSocket、微服务、TypeORM、Prisma。新手推荐度四星，适合有一定 JS / TS 基础的人。

NestJS 适合中大型 Node.js 后端、企业 API、微服务。如果你想要结构化、可维护的 Node 后端，NestJS 是首选。

### **Django**

Django 是 Python 的全包式 Web 框架，2005 年发布，成熟稳定。它自带 ORM、Admin 后台、认证、表单、模板、迁移、测试。你装完 Django，几乎不用选其他库，就能开发完整 Web 应用。Django Admin 尤其强大，几行代码就能生成管理后台。

Django 的学习成本中等，概念多，但文档极好。生态成熟，第三方包丰富。新手推荐度四星，适合做内容型网站、后台系统、快速开发。

Django 适合内容网站、CMS、电商、企业内部系统、需要 Admin 的项目。如果你用 Python 做全功能 Web，Django 很合适。

### **Flask**

Flask 是 Python 的微框架，轻量、灵活、简单。它只提供路由、请求、响应、模板，其他靠扩展。你可以自由选择 ORM、表单、认证库。Flask 适合小型 API、原型、学习。

Flask 学习成本低，一天能上手。生态好，扩展多。但大型项目需要自己架构。新手推荐度四星。

Flask 适合小 API、原型、微服务、学习 Web 开发。

### **FastAPI**

FastAPI 是 2018 年出现的现代 Python 框架，主打异步、类型提示、自动文档。你用 Python 类型标注参数，FastAPI 自动校验、生成 OpenAPI 文档、提供交互式 API 页面。它基于 Starlette 和 Pydantic，性能好，开发快。

FastAPI 的学习成本低到中。Python 类型提示是核心，异步需要理解。生态快速增长，支持 SQLAlchemy、Prisma、依赖注入、WebSocket、后台任务。新手推荐度五星，尤其适合 AI 应用、API 服务。

FastAPI 适合现代 API、AI 服务、微服务、数据接口。如果你用 Python 做后端，FastAPI 是当前最推荐的选择。

### **Spring Boot**

Spring Boot 是 Java 企业级框架，基于 Spring，简化配置。它提供自动配置、起步依赖、内嵌服务器、Actuator 监控。Spring Boot 生态极大，覆盖 Web、数据、安全、消息、批处理、云。大公司、金融、电商大量使用。

Spring Boot 学习成本高，概念多，配置复杂。但岗位多、稳定、性能好。新手推荐度三星，适合有 Java 基础、目标企业后端的人。

Spring Boot 适合大型企业应用、高并发服务、金融系统、微服务。

### **Go Gin**

Gin 是 Go 最流行的 Web 框架，高性能、简洁、中间件多。它提供路由、参数绑定、JSON 渲染、中间件、错误管理。Gin 性能极好，适合高并发 API。

Gin 学习成本中等，Go 基础好的人上手快。生态中等，但标准库强。新手推荐度四星。

Gin 适合高并发 API、微服务、云原生服务。

### **Laravel**

Laravel 是 PHP 最流行的现代框架，语法优雅，功能全。它有 Eloquent ORM、Blade 模板、Artisan 命令行、队列、事件、广播、认证、授权。Laravel 生态庞大，文档极好，社区活跃。

Laravel 学习成本低到中，PHP 基础好的人上手快。新手推荐度四星，适合建站、CMS、电商、API。

Laravel 适合 Web 应用、电商、CMS、SaaS、API。

### **Ruby on Rails**

Rails 是 Ruby 的全栈框架，约定优于配置，开发极快。它有 ActiveRecord ORM、Action Pack、Action View、迁移、测试、脚手架。Rails 适合 MVP、创业项目、内部工具。

Rails 学习成本中等，魔法多，新手容易迷惑。生态成熟但增长放缓。新手推荐度三星。

Rails 适合快速 MVP、内容网站、SaaS、内部工具。

### **后端框架选择建议**

Python 选 FastAPI（现代 API / AI）或 Django（全功能 Web）。Node.js 选 Express（小型）或 NestJS（中大型）。Java 选 Spring Boot。Go 选 Gin。PHP 选 Laravel。Ruby 选 Rails。

新手最稳的是 FastAPI + Python 或 Express / NestJS + TypeScript。这两个组合生态好、AI 友好、学习资源多。

## **4.3 移动端框架**

移动端框架分跨平台和原生。跨平台用一套代码跑 iOS 和 Android，原生各写一套。新手建议先跨平台，验证产品后再考虑原生。

### **React Native**

React Native 是 Meta 推出的跨平台框架，用 React 写移动端。你写组件，React Native 把它们映射成原生 UI。JS 逻辑跑在 JS 线程，UI 跑在原生线程。生态大，社区活跃，支持热重载、原生模块、第三方库。

学习成本中等，React 基础好的人上手快。新手推荐度四星。适合跨平台 App、前端团队转型。

### **Flutter**

Flutter 是 Google 推出的跨平台框架，用 Dart。它自绘 UI，不依赖原生组件，所以 UI 一致性极好，性能接近原生。Flutter 的热重载、Widget 系统、Material / Cupertino 组件库都很成熟。

学习成本中等，Dart 需要学，但语法不难。生态大，增长快。新手推荐度四星。适合追求 UI 一致性和性能的跨平台 App。

### **SwiftUI**

SwiftUI 是 Apple 的声明式 UI 框架，用 Swift。它语法简洁，预览强大，和 Apple 生态深度集成。学习成本中等，需要 Mac 和 Xcode。新手推荐度四星，适合只做 iOS / macOS 的人。

### **Jetpack Compose**

Compose 是 Android 的声明式 UI 框架，用 Kotlin。它替代 XML 布局，代码更简洁，预览方便。学习成本中等，Android 基础好的人上手快。新手推荐度四星，适合只做 Android 的人。

### **移动端框架选择建议**

跨平台选 React Native（有前端基础）或 Flutter（追求 UI 一致）。原生 iOS 选 SwiftUI，原生 Android 选 Jetpack Compose。

## **4.4 桌面端框架**

桌面端框架分 Web 技术和原生。Web 技术门槛低，原生性能好。

### **Electron**

Electron 用 HTML / CSS / JS 写桌面应用，套 Chromium 和 Node.js。VS Code、Slack、Discord 都用它。生态极大，学习成本低到中。缺点是体积大、内存高。新手推荐度四星。

### **Tauri**

Tauri 用前端写界面，Rust 写后端。体积小、性能好、更安全。生态增长中，学习成本中高，需要一点 Rust。新手推荐度三星。

### **桌面端框架选择建议**

新手选 Electron，快速出成果。在意体积和性能，选 Tauri。

## **4.5 AI 应用框架**

AI 应用框架帮你连接模型、数据、工具、记忆。下面介绍主流选择。

### **LangChain**

LangChain 是最流行的 LLM 应用框架，提供链、Agent、工具、记忆、RAG、回调。支持 Python 和 JavaScript。生态大，但更新快，API 变化多。学习成本中等。新手推荐度四星。

### **LlamaIndex**

LlamaIndex 专注数据索引和检索，适合 RAG、知识库问答。它提供文档加载、分割、嵌入、索引、查询、Agent。生态好，文档清晰。学习成本中等。新手推荐度四星。

### **Transformers**

Transformers 是 Hugging Face 的模型库，提供数千个预训练模型。你可以加载、微调、推理。适合 NLP、本地模型、研究。学习成本中高。新手推荐度四星。

### **AI 框架选择建议**

做 RAG 和知识库，选 LlamaIndex。做 Agent 和复杂链，选 LangChain。做本地模型和微调，选 Transformers。新手可以先不用框架，直接调 API，理解原理后再上框架。

## **4.6 框架选择的核心思路**

框架选择没有唯一答案。新手最稳的策略是：选主流、选生态大、选 AI 熟悉、选文档好。不要为了“酷”选冷门框架，不要一次学多个框架，不要忽略版本兼容。

如果你做 Web 全栈，Next.js + FastAPI / NestJS 是最稳组合。如果你做 AI 应用，FastAPI + LangChain / LlamaIndex + Next.js 是最稳组合。如果你做移动，React Native 或 Flutter。如果你做桌面，Electron 或 Tauri。
