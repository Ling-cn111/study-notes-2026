## 第五章：泛型、特征与生命周期

### ① 核心概念

**一句话总结：**
> 泛型让你写"能处理多种类型"的代码而无需重复，特征（trait）定义类型之间的"行为契约"，生命周期标注告诉编译器引用之间"谁活得比谁久"——这三者共同构成了 Rust 零成本抽象的基础。

**生活类比：**
- **泛型** = 通用充电器接口——Type-C 口，不管什么手机，插上就能充；不需要为每款手机造不同的充电器
- **特征（trait）** = "能吃"这个能力——你、猫、狗都能"吃"，但吃的食物不同；trait 只定义了"能吃"这个接口，具体实现各不一样
- **生命周期** = 图书馆借书——书（引用）不能比图书馆（数据源头）存在得更久。如果你借了一本书，图书馆关了，你的书就成了"幽灵书"
- **trait bound** = 招聘要求——"应聘者必须会写代码"，泛型 T 必须实现了某个 trait 才能使用

**用 C 的视角理解：**
- **泛型** ≈ C 的宏 (`#define max(a,b) ((a)>(b)?(a):(b)`) 但有类型安全 + C++ 模板的零成本
- **trait** ≈ C 的虚函数表（vtable）+ 接口概念，但 Rust 的 trait 既可以静态分发（编译期展开，零开销），也可以动态分发（运行时查表）
- **trait bound** ≈ C 中函数指针作为参数的前提，但类型安全且在编译时检查
- **生命周期 'a** ≈ 编译器自动帮你检查指针是不是悬垂了——C 中完全靠程序员自觉

**Rust 中的三种"抽象方式"对比：**

| 抽象方式 | 用途 | 开销 | 类似 C |
|---------|------|------|--------|
| 泛型 `<T>` | 类型参数化，写一次用多种类型 | 编译期单态化，零运行时开销 | 宏 / C++ 模板 |
| trait `impl Trait` | 定义共享行为接口 | 静态分发零开销，动态分发有 vtable 开销 | 虚函数 / 接口 |
| 生命周期 `'a` | 描述引用之间的关系 | 纯编译期概念，零运行时开销 | 无对应（C 全靠手动） |

### ② 为什么需要它？

**解决什么痛点？**

1. **写重复代码**：C 中要为 `int`、`float`、`double` 各写一个排序函数——宏可以避免但类型不安全
2. **没有接口抽象**：C 中实现"通用"函数只能靠 `void*` + 函数指针，类型不安全且易出错
3. **悬垂引用**：C 中返回局部变量地址毫无警告，运行时就崩溃——Rust 用生命周期彻底解决
4. **编译时 vs 运行时开销**：C++ 的虚函数有运行时开销（vtable 查找、无法内联），Rust 的 trait 可以在编译时展开（零开销）

**Rust 的方案：**

```
问题：写一个"找出最大值"的函数，支持任意可比较类型

C 的解法（宏，不安全）：
    #define max(a,b) ((a)>(b)?(a):(b))
    // 问题：无类型检查，多次求值

C++ 的解法（模板，编译慢，错误信息恐怖）：
    template<typename T>
    T max(T a, T b) { return a > b ? a : b; }

Rust 的解法（泛型 + trait bound，清晰安全）：
    fn max<T: PartialOrd>(a: T, b: T) -> T {
        if a > b { a } else { b }
    }
```

**抽象层次对比：**

```
泛型 = "我想对任意类型 T 做同样的事"
trait = "我想要求 T 必须能做什么"
生命周期 = "我想保证引用不会悬空"
三者组合起来：fn process<'a, T: Display>(x: &'a T) -> &'a str
"对任何实现了 Display 的类型 T，接受一个生命周期为 'a 的引用，返回一个相同生命周期的 &str"
```

### ③ 精简代码示例

**泛型函数——找最大值：**

```rust
// PartialOrd 是"可以比较大小"的 trait
fn largest<T: PartialOrd>(list: &[T]) -> &T {
    let mut largest = &list[0];
    for item in list {
        if item > largest {
            largest = item;
        }
    }
    largest
}

fn main() {
    let numbers = vec![34, 50, 25, 100, 65];
    println!("最大数: {}", largest(&numbers));  // 100
    
    let chars = vec!['y', 'm', 'a', 'q'];
    println!("最大字符: {}", largest(&chars));  // 'y'
    
    let floats = vec![1.1, 3.3, 2.2, 5.5];
    println!("最大浮点: {}", largest(&floats));  // 5.5
}
```

**定义和实现 trait——详细示例：**

```rust
// 定义 trait
trait Summary {
    // 必须实现的方法（没有默认实现）
    fn summarize(&self) -> String;
    
    // 有默认实现的方法
    fn default_summary(&self) -> String {
        String::from("（未提供摘要）")
    }
}

// 为不同类型实现 Summary trait
struct Article {
    title: String,
    content: String,
}

impl Summary for Article {
    fn summarize(&self) -> String {
        let preview: String = self.content.chars().take(20).collect();
        format!("{}: {}...", self.title, preview)
    }
    // default_summary 使用默认实现
}

struct Tweet {
    username: String,
    content: String,
}

impl Summary for Tweet {
    fn summarize(&self) -> String {
        format!("@{}: {}", self.username, self.content)
    }
    
    // 也可以覆盖默认实现
    fn default_summary(&self) -> String {
        format!("[推文] {}", self.summarize())
    }
}

fn main() {
    let article = Article {
        title: "Rust 入门".to_string(),
        content: "Rust 是一门系统编程语言...".to_string(),
    };
    let tweet = Tweet {
        username: "rustacean".to_string(),
        content: "学习了所有权，太棒了！".to_string(),
    };
    
    println!("{}", article.summarize());
    println!("{}", tweet.summarize());
    println!("默认: {}", article.default_summary());
}
```

**Trait 作为参数——几种写法：**

```rust
trait Summary { fn summarize(&self) -> String; }

// 写法 1：impl Trait 语法（最简洁，静态分发）
fn notify(item: &impl Summary) {
    println!("快讯！{}", item.summarize());
}

// 写法 2：Trait Bound 语法（等价，更适合多参数）
fn notify2<T: Summary>(item: &T) {
    println!("快讯！{}", item.summarize());
}

// 写法 3：where 子句（多个约束更清晰）
fn notify3<T>(item: &T)
where
    T: Summary,
{
    println!("快讯！{}", item.summarize());
}

// 多个 trait 约束
fn display1(item: &(impl Summary + Display)) {}
fn display2<T: Summary + Display>(item: &T) {}
fn display3<T>(item: &T) where T: Summary + Display {}

// 返回 impl Trait
fn returns_summarizable() -> impl Summary {
    Tweet {
        username: "rust".to_string(),
        content: "Rust 是安全的！".to_string(),
    }
}
// 注意：不能返回多种实现 impl Trait 的类型

// 条件实现（Blanket Implementation）
impl<T: Display> ToString for T {
```

```rust
trait Iterator {
```

**生命周期——为什么需要它：**

```rust
// 最经典的例子：返回两个字符串中较长的一个
//
// 编译器不知道返回的引用来自 x 还是 y
// 所以无法确定返回值的生命周期
//
// fn longest(x: &str, y: &str) -> &str {
//     if x.len() > y.len() { x } else { y }
// }
// error[E0106]: missing lifetime specifier

// 正确写法：用 'a 标注，告诉编译器
// "返回的引用和 x、y 有相同的生命周期"
// 'a 的具体长度 = x 和 y 的生命周期中较短的那个
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}

fn main() {
    let string1 = String::from("长字符串");
    let result;
    
    {
        let string2 = String::from("短");
        result = longest(&string1, &string2);
        // 'a 是 string1 和 string2 中较短的那个（string2 的生命周期）
        // 所以 result 的有效范围 = string2 的有效范围
        println!("较长的是: {}", result);  // OK
    }
    
    // println!("{}", result);
    // 错误！result 的生命周期在这里已经结束了
    // （因为 string2 已经释放）
}
```

**结构体中的生命周期：**

```rust
// 当结构体包含引用时，必须标注生命周期
struct Excerpt<'a> {
    part: &'a str,  // Excerpt 不能比 part 活得更久
}

impl<'a> Excerpt<'a> {
    fn announce_and_return_part(&self, announcement: &str) -> &str {
        println!("请注意: {}", announcement);
        self.part  // 返回 self.part，其生命周期和 self 相同
    }
}

fn main() {
    let novel = String::from("从前有座山。山里有座庙。庙里有个和尚。");
    let first_sentence = novel.split('.').next().expect("没有找到句号");
    
    let excerpt = Excerpt {
        part: first_sentence,  // excerpt 引用了 novel 的部分数据
    };
    // OK：excerpt 在 novel 之后才被释放
    println!("{}", excerpt.part);  // "从前有座山"
}
```

**生命周期省略规则——不用写生命周期的情况：**

```rust
// 在日常代码中，大部分情况下不需要显式标注生命周期
// 这是因为 Rust 有"省略规则"（lifetime elision rules）

// 规则 1：每个引用参数都有自己的生命周期
// 规则 2：只有一个输入生命周期时，输出继承它的生命周期
// 规则 3：方法中 &self 的生命周期传给返回值

// 下面这些函数，编译器会自动推算出生命周期：
fn first_word(s: &str) -> &str {  // 'a in, 'a out
    // ...
}

fn print(s: &str) {  // 不需要生命周期
    println!("{}", s);
}

// 当有多个输入引用时，编译器无法推断，需要手动标注
// fn longest(x: &str, y: &str) -> &str  // 错误！需要标注
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {  // 手动标注
    if x.len() > y.len() { x } else { y }
}
```

**Derive（派生宏）——用 #[derive] 自动实现 trait：**

```rust
// Rust 可以自动为 struct/enum 派生一些常见 trait

#[derive(Debug)]                           // 格式化 {:?} 输出
#[derive(PartialEq, Eq)]                   // == 和 != 比较
#[derive(PartialOrd, Ord)]                  // < > <= >= 排序
#[derive(Clone)]                            // 显式 .clone() 方法
#[derive(Copy)]                             // 赋值自动复制（需要 Clone）
#[derive(Hash)]                             // 可以用作 HashMap 的键
#[derive(Default)]                          // 提供默认值 Default::default()

struct Person {
    name: String,
    age: u32,
}

fn main() {
    let p1 = Person {
        name: "Alice".to_string(),
        age: 30,
    };
    let p2 = p1.clone();  // 因为派生了 Clone
    
    println!("{:?}", p1);  // 因为派生了 Debug
}
```

**Trait Object（动态分发）——Box<dyn Trait>：**

```rust
trait Animal {
    fn make_sound(&self);
}

struct Dog;
struct Cat;
struct Cow;

impl Animal for Dog {
    fn make_sound(&self) { println!("汪汪！"); }
}
impl Animal for Cat {
    fn make_sound(&self) { println!("喵喵！"); }
}
impl Animal for Cow {
    fn make_sound(&self) { println!("哞～"); }
}

fn main() {
    // 静态分发（编译时确定类型）
    let dog = Dog;
    dog.make_sound();  // 直接调用，可内联
    
    // 动态分发（运行时确定类型）
    let animals: Vec<Box<dyn Animal>> = vec![
        Box::new(Dog),
        Box::new(Cat),
        Box::new(Cow),
    ];
    
    for animal in &animals {
        animal.make_sound();  // 通过 vtable 调用
    }
}
```

**关键点说明：**

| 概念 | 说明 | 注意 |
|------|------|------|
| 泛型 `<T>` | 类型参数化 | 编译期单态化，不产生运行时开销 |
| trait | 行为接口 | 可静态分发（零开销）或动态分发（vtable） |
| `impl Trait` | 参数/返回值的 trait 语法糖 | 适用于简单场景 |
| `where` 子句 | 多约束时的清晰写法 | `fn foo<T>() where T: Trait1 + Trait2` |
| 关联类型 | trait 内部的占位类型 | 每个实现只能关联一个类型 |
| 生命周期 `'a` | 引用存活时间的标注 | 纯编译期概念，零运行时 |
| `'static` | 程序整个运行期 | 字符串字面量是 'static |
| 省略规则 | 编译器自动推断生命周期 | 大部分情况不用写 |
| `#[derive]` | 自动实现 trait | Debug, Clone, PartialEq 最常用 |
| `Box<dyn Trait>` | 动态分发 | 有 vtable 开销，无法内联 |
