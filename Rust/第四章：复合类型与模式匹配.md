## 第四章：复合类型与模式匹配

### ① 核心概念

**一句话总结：**
> Rust 用 struct 组织数据、用 enum 表达"可能的情况集合"、用模式匹配安全地解构它们——编译器保证你处理了所有分支，杜绝了空指针和未定义行为。

**生活类比：**
- **struct** = 一张个人信息表（姓名、年龄、邮箱）——字段名 + 字段值
- **tuple struct** = 医院病历编号（String, u32, bool）——字段没有名字，靠位置区分
- **enum** = 天气预报：晴（不带数据）、雨（带降水量）、雪（带积雪深度）——每种情况可以有不同种类的数据
- **match** = 交警看信号灯：红灯停、绿灯行、黄灯等——必须处理所有颜色，否则被批评（编译错误）
- **if let** = 只关心红灯的情况，别的颜色不管——只匹配一种模式，省略其他

**用 C 的视角理解：**

| C 的概念 | Rust 对应 | 关键差异 |
|---------|-----------|---------|
| `struct` | `struct` | Rust 的 struct 可以有方法（`impl`） |
| `union` | `enum` | C 的 union 不安全（不知道当前是哪个变体），Rust 的 enum 带标签 |
| `switch` | `match` | C 的 switch 需要 break 防止穿透，Rust 的 match 不会穿透，且必须穷举 |
| `NULL` 指针 | `Option<T>` | Option 是 enum，编译器强制你处理 `None` 的情况 |
| `int` 返回值错误码 | `Result<T, E>` | Result 是 enum，编译器强制你处理 `Err` 的情况 |

---

### ② 为什么需要它？

**解决什么痛点？**

1. **C 的 union 没有类型安全**：你无法知道当前 union 中存的是 int 还是 float——读取错误的字段是未定义行为
2. **C 的 switch 容易出 bug**：忘记加 break 产生穿透、忘记处理某个 case——Rust 的 match 杜绝这些问题
3. **NULL 指针是十亿美元错误**（Tony Hoare 原话）：C 中每个指针都可能为 NULL，没人检查——Rust 用 `Option<T>` 消灭空指针
4. **C 的函数和数据结构分离**：操作 struct 的函数只能单独定义，不能"属于"结构体——Rust 的 `impl` 把它们捆绑在一起
5. **缺少构造函数**：C 的 struct 没有构造函数，需要手动写 `init_xxx` 函数

**Rust 的方案：**

| 特性 | 解决什么问题 | 如何使用 |
|------|-------------|---------|
| `struct` + `impl` | 数据 + 方法封装 | 类似 C++ 的类，但只有单继承（通过 trait） |
| `enum` + 数据关联 | 安全的 tagged union | `enum Option<T> { Some(T), None }` |
| `match` | 安全的模式匹配 | 必须穷举，否则编译错误 |
| `if let` | 只关注一种模式 | 简化单个模式的匹配 |
| 解构（destructure） | 方便提取数据 | `let User { name, age } = user;` |

### ③ 精简代码示例

**struct 的三种形式：**

```rust
// 1. 命名结构体（C 风格）——最常用
struct User {
    username: String,
    email: String,
    sign_in_count: u64,
    active: bool,
}

// 2. 元组结构体（Tuple Struct）——字段没有名字，靠位置访问
struct Color(i32, i32, i32);
struct Point(i32, i32, i32);

// 3. 单元结构体（Unit-like Struct）——没有字段，用于标记类型
struct AlwaysEqual;  // 类似一个"标记"

fn main() {
    // --- 命名结构体 ---
    let mut user1 = User {
        username: String::from("Alice"),
        email: String::from("alice@example.com"),
        sign_in_count: 1,
        active: true,
    };
    user1.email = String::from("alice@new.com");  // 修改
    
    // 从另一个实例创建（Struct Update Syntax）
    let user2 = User {
        email: String::from("bob@example.com"),
        ..user1  // 其余字段从 user1 拷贝
    };
    // 注意：如果字段是 String（非 Copy），..user1 会 move 未显式赋值的字段
    // user1.username 已经 move 给 user2，不能再用了
    // user1.sign_in_count 和 user1.active 是 Copy 类型，还能用
    
    // --- 元组结构体 ---
    let black = Color(0, 0, 0);
    let origin = Point(0, 0, 0);
    // Color 和 Point 是不同的类型！即使内部结构相同
    // black == origin  // 编译错误！类型不匹配
    
    println!("黑色: ({}, {}, {})", black.0, black.1, black.2);
    
    // 解构元组结构体
    let Point(x, y, z) = origin;
    println!("原点: ({}, {}, {})", x, y, z);
    
    // --- 单元结构体 ---
    let marker = AlwaysEqual;
}
```

**为 struct 添加方法（impl 块）：**

```rust
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    // 方法：&self 是当前实例的不可变引用
    fn area(&self) -> u32 {
        self.width * self.height
    }
    
    // 方法：&mut self 是可变引用
    fn scale(&mut self, factor: u32) {
        self.width *= factor;
        self.height *= factor;
    }
    
    // 方法：可以接受其他参数
    fn can_hold(&self, other: &Rectangle) -> bool {
        self.width > other.width && self.height > other.height
    }
    
    // 关联函数（类似 C++ 的静态方法 / Java 的 static 方法）
    // 注意：没有 &self 参数
    fn square(size: u32) -> Rectangle {
        Rectangle {
            width: size,
            height: size,
        }
    }
    
    // Getter 方法（Rust 惯例：不使用 get_ 前缀）
    fn width(&self) -> u32 {
        self.width
    }
}

fn main() {
    let mut rect = Rectangle {
        width: 30,
        height: 50,
    };
    
    println!("面积: {}", rect.area());        // 1500
    rect.scale(2);
    println!("缩放后面积: {}", rect.area());  // 6000
    
    let sq = Rectangle::square(20);  // 用 :: 调用关联函数
    println!("正方形面积: {}", sq.area());
    
    println!("宽度: {}", rect.width());  // getter
}
```

**enum 的灵活用法：**

```rust
// 枚举变体可以带不同类型的数据
enum Message {
    Quit,                        // 不带数据
    Move { x: i32, y: i32 },     // 匿名结构体
    Write(String),               // 单个字符串
    ChangeColor(i32, i32, i32),  // 三个整数
}

// enum 也可以有方法！（是的，enum 和 struct 一样都能有 impl）
impl Message {
    fn call(&self) {
        // 方法体
        match self {
            Message::Quit => println!("退出"),
            Message::Move { x, y } => println!("移动到 ({}, {})", x, y),
            Message::Write(text) => println!("写入: {}", text),
            Message::ChangeColor(r, g, b) => println!("颜色: ({}, {}, {})", r, g, b),
        }
    }
}

fn main() {
    let msgs = vec![
        Message::Quit,
        Message::Move { x: 10, y: 20 },
        Message::Write(String::from("hello")),
        Message::ChangeColor(255, 0, 0),
    ];
    
    for msg in &msgs {
        msg.call();
    }
}
```

**match 的多种用法——深入：**

```rust
enum Coin {
    Penny,
    Nickel,
    Dime,
    Quarter,
}

fn value_in_cents(coin: Coin) -> u8 {
    match coin {
        Coin::Penny => {
            println!("幸运便士！");
            1  // 多行时用代码块
        },
        Coin::Nickel => 5,
        Coin::Dime => 10,
        Coin::Quarter => 25,
        // 编译器检查：所有分支都已处理 ✓
    }
}

// match 绑定——匹配时提取内部数据
#[derive(Debug)]
enum UsState {
    Alabama,
    Alaska,
    // ...
}

enum Coin2 {
    Penny,
    Nickel,
    Dime,
    Quarter(UsState),  // 25 美分硬币附带州名
}

fn value_in_cents2(coin: Coin2) -> u8 {
    match coin {
        Coin2::Penny => 1,
        Coin2::Nickel => 5,
        Coin2::Dime => 10,
        Coin2::Quarter(state) => {  // 这里绑定了 state
            println!("来自 {:?} 的 25 美分！", state);
            25
        }
    }
}
```

**match 的复杂模式——守卫（guard）和 @ 绑定：**

```rust
fn main() {
    let num = Some(4);
    
    match num {
        Some(x) if x < 5 => println!("小于 5: {}", x),   // match guard
        Some(x) => println!("大于等于 5: {}", x),
        None => (),
    }
    
    // @ 绑定：将模式匹配的值绑定到变量
    enum Message {
        Hello { id: i32 },
    }
    
    let msg = Message::Hello { id: 5 };
    
    match msg {
        Message::Hello {
            id: id_variable @ 3..=7,  // id 在 3-7 之间
        } => println!("id 在范围内: {}", id_variable),
        Message::Hello {
            id: 10..=12,  // 只匹配范围，不绑定值
        } => println!("id 在 10-12 之间"),
        Message::Hello { id } => println!("其他 id: {}", id),
    }
}
```

**Option<T>——Rust 的"空值"（核心！）：**

```rust
// Option<T> 的定义（标准库）：
// enum Option<T> {
//     Some(T),
//     None,
// }

fn main() {
    let some_number = Some(5);          // Option<i32>
    let some_string = Some("hello");   // Option<&str>
    let absent_number: Option<i32> = None;  // 必须显式指定类型
    
    // Option 不能直接和普通值运算
    let x: i8 = 5;
    let y: Option<i8> = Some(5);
    // let sum = x + y;  // 编译错误！类型不匹配
    
    // 必须先用 match 取出内部值
    match y {
        Some(n) => println!("x + y = {}", x + n),
        None => println!("y 没有值"),
    }
    
    // 或者用 unwrap（危险——可能 panic）
    let z = y.unwrap();  // 如果 y 是 None，这里会 panic！
    println!("{}", x + z);
    
    // 安全的解包方式
    let result = y.unwrap_or(0);  // 如果是 None，用 0 替代
}
```

**if let——只关注一种模式的简化写法：**

```rust
fn main() {
    let some_value = Some(3);
    
    // match 写法（完整但啰嗦）
    match some_value {
        Some(3) => println!("是 3"),
        _ => (),  // 其他情况必须处理，但什么都不做
    }
    
    // if let 写法（只关心一种模式时更简洁）
    if let Some(3) = some_value {
        println!("是 3");
    }  // 不需要写 _ => ()
    
    // while let——循环匹配
    let mut stack = vec![1, 2, 3];
    while let Some(top) = stack.pop() {
        println!("弹出: {}", top);
    }
    // 输出：3, 2, 1
    
    // 结合 else
    let value = Some(42);
    if let Some(x) = value {
        println!("值: {}", x);
    } else {
        println!("没有值");
    }
}
```

**模式匹配的其他用法——不仅仅在 match：**

```rust
fn main() {
    // 1. let 解构
    let point = (3, 5);
    let (x, y) = point;
    println!("({}, {})", x, y);
    
    // 2. 函数参数解构
    struct User { name: String, age: u32 }
    let user = User { name: "Alice".to_string(), age: 30 };
    print_user(user);
    
    // 3. for 循环中的模式匹配
    let pairs = [(1, 2), (3, 4), (5, 6)];
    for (a, b) in pairs {
        println!("a={}, b={}", a, b);
    }
    
    // 4. if 表达式中的 let
    let condition = Some(5);
    if let Some(x) = condition {
        println!("x = {}", x);
    }
    
    // 5. match 中使用 _ 忽略
    let num = 42;
    match num {
        1 => println!("一"),
        2 => println!("二"),
        _ => println!("其他"),  // _ 匹配所有
    }
    
    // 6. 用 | 匹配多个模式
    match num {
        1 | 2 | 3 => println!("小数字"),
        4..=10 => println!("中数字"),
        _ => println!("大数字"),
    }
}

fn print_user(User { name, age }: User) {
    println!("{} ({})", name, age);
}
```

**关键点说明：**

| 概念 | 关键点 |
|------|--------|
| struct | 三种形式：命名、元组、单元；字段可以带 `pub` 控制可见性 |
| impl | 为 struct/enum 添加方法；`&self` 是实例方法，无 `self` 是关联函数（类似 static） |
| enum | 变体可以带数据；本身就是一个类型；可以有方法 |
| match | 必须穷举；每个分支是 `模式 => 表达式`；不会穿透（无 break 问题） |
| if let | 单模式匹配的语法糖；可以跟 else |
| Option | 替代 NULL 指针；用 `match` / `unwrap_or` / `?` 处理 |
| 解构 | let、函数参数、match 都可以解构 struct/tuple/enum |
| 匹配守卫 | `match x { pattern if condition => ... }` |
| @ 绑定 | `id @ 1..=5 =>` 匹配并绑定值 |
