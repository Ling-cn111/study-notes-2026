## 第六章：错误处理与集合类型

### ① 核心概念

**一句话总结：**
> Rust 没有异常机制，而是用 `Result<T, E>` 处理可恢复错误、`panic!` 处理不可恢复错误；集合类型提供了标准的高性能数据结构——`Vec`、`HashMap`、`String` 是日常使用频率最高的三种。

**生活类比：**
- **Result<T, E>** = 去取快递——可能拿到包裹（`Ok(T)`），也可能被告知"没找到"（`Err(E)`）——两者都是正常预期中的情况
- **panic!** = 系统灾难——比如硬盘物理损坏，没法恢复，直接停机报警
- **? 运算符** = 快递站的"自动处理"——如果包裹没找到，自动上报给上级站点；如果找到了，自动拆箱递给你
- **Vec<T>** = 一个会自动扩容的行李箱——东西放得下就放，放不下自动换更大的箱子
- **HashMap<K, V>** = 查字典——输入键，找到对应的值
- **String** = 一个会自动管理内存的字符串，像 C++ 的 `std::string` 但保证 UTF-8 编码

**用 C 的视角理解：**

| Rust 概念 | C 对应 | 优势 |
|-----------|--------|------|
| `Result<T, E>` | `int` 返回值 + `errno` / 传出参数 | 类型安全，必须处理 |
| `panic!` | `assert()` + `abort()` | 更清晰的错误信息 |
| `?` 运算符 | `if (ret < 0) return ret;` | 一行搞定 |
| `Vec<T>` | 动态数组 / `realloc` | 自动内存管理 |
| `HashMap<K,V>` | 都没有标准实现 | 开箱即用，性能好 |
| `String` | `char*` + `malloc`/`free` | 自动管理，保证 UTF-8 |

### ② 为什么需要它？

**解决什么痛点？**

1. **忘记检查错误**：C 中忽略函数返回值是常见的 Bug 来源（调用 `printf` 返回值？不检查！）。Rust 的 `Result` 用 `#[must_use]` 标注，编译器**警告**你忽略它
2. **异常开销**：C++/Java 异常有运行时开销（栈展开、RAII 的额外代码），即使没有抛出异常也有成本。Rust 的 `Result` 是普通返回值，零额外开销
3. **区分可恢复 vs 不可恢复**：C 中 `assert(ptr != NULL)` 和 `if (ptr == NULL) return -1` 都在用，但没有语言层的区分。Rust 明确区分 `Result`（可处理）和 `panic!`（不可恢复）
4. **动态数组手动管理**：C 中 `realloc` 容易忘、容易错——忘记更新 `size`、忘记检查返回值
5. **String 管理复杂**：C 的字符串要手动管理内存、要关心 `\0` 终止符、要防止缓冲区溢出

**核心作用速览：**

| 类型/机制 | 用途 | 关键方法 |
|-----------|------|---------|
| `Result<T, E>` | 可恢复错误 | `.unwrap()`, `?`, `.map()`, `.and_then()` |
| `panic!` | 不可恢复错误 | 程序终止，栈展开（可选 abort） |
| `Vec<T>` | 动态数组 | `.push()`, `.pop()`, `.get()`, `.iter()` |
| `HashMap<K,V>` | 哈希表 | `.insert()`, `.get()`, `.entry()`, `.remove()` |
| `String` | UTF-8 字符串 | `.push_str()`, `.len()`, `.replace()`, `.split()` |

### ③ 精简代码示例

**Result 的完整用法——打开文件：**

```rust
use std::fs::File;
use std::io::{self, Read};

// 方式 1：用 match 处理 Result
fn read_username_v1(path: &str) -> Result<String, io::Error> {
    let f = File::open(path);
    let mut file = match f {
        Ok(file) => file,
        Err(e) => return Err(e),
    };
    
    let mut username = String::new();
    match file.read_to_string(&mut username) {
        Ok(_) => Ok(username.trim().to_string()),
        Err(e) => Err(e),
    }
}

// 方式 2：用 ? 运算符（最常用，最简洁）
fn read_username_v2(path: &str) -> Result<String, io::Error> {
    let mut file = File::open(path)?;      // Err 时提前 return
    let mut username = String::new();
    file.read_to_string(&mut username)?;   // Err 时提前 return
    Ok(username.trim().to_string())
}

// 方式 3：链式调用
fn read_username_v3(path: &str) -> Result<String, io::Error> {
    let mut username = String::new();
    File::open(path)?
        .read_to_string(&mut username)?;
    Ok(username.trim().to_string())
}

// 方式 4：终极简洁——标准库已经提供了
fn read_username_v4(path: &str) -> Result<String, io::Error> {
    fs::read_to_string(path)  // 一行搞定
}

fn main() {
    match read_username_v2("user.txt") {
        Ok(name) => println!("用户名: {}", name),
        Err(e) => eprintln!("读取失败: {}", e),
    }
}
```

**? 运算符的细节——可以在任何实现了 From trait 的场景使用：**

```rust
use std::num::ParseIntError;
use std::fs;

// ? 会自动将错误类型转换为函数的返回错误类型
// 只要实现了 From<ParseIntError> for MyError
fn parse_file(path: &str) -> Result<i32, Box<dyn std::error::Error>> {
    let content = fs::read_to_string(path)?;     // io::Error → Box<dyn Error>
    let num = content.trim().parse::<i32>()?;     // ParseIntError → Box<dyn Error>
    Ok(num)
}

// 自定义错误转换
#[derive(Debug)]
enum MyError {
    Io(io::Error),
    Parse(ParseIntError),
}

impl From<io::Error> for MyError {
    fn from(e: io::Error) -> MyError { MyError::Io(e) }
}

impl From<ParseIntError> for MyError {
    fn from(e: ParseIntError) -> MyError { MyError::Parse(e) }
}

fn process(path: &str) -> Result<i32, MyError> {
    let content = fs::read_to_string(path)?;  // io::Error → MyError
    let num = content.trim().parse::<i32>()?; // ParseIntError → MyError
    Ok(num)
}
```

**map 和 and_then——链式处理 Result：**

```rust
fn main() {
    // map：对 Ok 中的值做变换
    let result = "42".parse::<i32>();
    let doubled = result.map(|n| n * 2);
    println!("{:?}", doubled);  // Ok(84)
    
    // map_err：对 Err 中的值做变换
    let result = "not_a_number".parse::<i32>();
    let with_context = result.map_err(|e| {
        format!("解析失败: {}", e)
    });
    println!("{:?}", with_context);  // Err("解析失败: invalid digit found in string")
    
    // and_then：链式调用返回 Result 的函数
    fn parse_and_double(s: &str) -> Result<i32, ParseIntError> {
        s.parse::<i32>().map(|n| n * 2)
    }
    
    fn stringify(n: i32) -> Result<String, ()> {
        Ok(format!("数字: {}", n))
    }
    
    let result = "42"
        .parse::<i32>()
        .map(|n| n * 2)
        .and_then(|n| stringify(n));
    println!("{:?}", result);  // Ok("数字: 84")
}
```

**自定义错误类型——定义自己的 Result：**

```rust
use std::fmt;

#[derive(Debug)]
enum AppError {
    NotFound(String),
    PermissionDenied,
    InvalidInput { field: String, detail: String },
    DatabaseError(String),
}

// 实现 Display trait 以便显示友好的错误信息
impl fmt::Display for AppError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            AppError::NotFound(item) => write!(f, "未找到: {}", item),
            AppError::PermissionDenied => write!(f, "权限不足"),
            AppError::InvalidInput { field, detail } => {
                write!(f, "输入错误 [{}]: {}", field, detail)
            }
            AppError::DatabaseError(msg) => write!(f, "数据库错误: {}", msg),
        }
    }
}

// 实现 std::error::Error trait（可选，但推荐）
impl std::error::Error for AppError {}

// 自定义 Result 别名（可选）
type AppResult<T> = Result<T, AppError>;

fn find_user(id: i32) -> AppResult<String> {
    match id {
        1 => Ok("Alice".to_string()),
        2 => Ok("Bob".to_string()),
        _ => Err(AppError::NotFound(format!("用户 {}", id))),
    }
}

fn main() {
    match find_user(3) {
        Ok(name) => println!("找到: {}", name),
        Err(e) => eprintln!("错误: {}", e),
    }
}
```

**Vec<T>——动态数组完整用法：**

```rust
fn main() {
    // ---------- 创建 ----------
    let mut v1: Vec<i32> = Vec::new();
    let v2 = vec![1, 2, 3, 4, 5];       // vec! 宏
    let v3 = vec![0; 10];                // 10 个 0
    
    // ---------- 增删改 ----------
    v1.push(10);
    v1.push(20);
    v1.push(30);
    
    v1.pop();  // 弹出 30，v1 = [10, 20]
    
    v1.insert(1, 15);  // 在索引 1 处插入，v1 = [10, 15, 20]
    v1.remove(0);      // 删除索引 0 的元素，v1 = [15, 20]
    
    // ---------- 访问 ----------
    // 索引访问（越界会 panic！）
    let second = &v1[1];  // 20
    
    // 安全访问（返回 Option）
    match v1.get(100) {
        Some(val) => println!("值: {}", val),
        None => println!("索引越界"),
    }
    
    // ---------- 遍历 ----------
    // 不可变遍历
    for item in &v2 {
        println!("{}", item);
    }
    
    // 可变遍历（修改每个元素）
    let mut squares = vec![1, 2, 3, 4, 5];
    for item in &mut squares {
        *item = *item * *item;
    }
    println!("{:?}", squares);  // [1, 4, 9, 16, 25]
    
    // 带索引遍历
    for (i, item) in squares.iter().enumerate() {
        println!("squares[{}] = {}", i, item);
    }
    
    // ---------- 常见操作 ----------
    let numbers = vec![4, 2, 5, 1, 3];
    let sum: i32 = numbers.iter().sum();
    let max = numbers.iter().max().unwrap();
    let min = numbers.iter().min().unwrap();
    
    // 排序（原地）
    let mut sorted = numbers.clone();  // 因为 numbers 不可变
    sorted.sort();
    println!("{:?}", sorted);  // [1, 2, 3, 4, 5]
    
    // 过滤
    let evens: Vec<&i32> = numbers.iter().filter(|&x| x % 2 == 0).collect();
    println!("{:?}", evens);  // [4, 2]
    
    // 映射
    let doubled: Vec<i32> = numbers.iter().map(|x| x * 2).collect();
}
```

**HashMap<K, V>——哈希表完整用法：**

```rust
use std::collections::HashMap;

fn main() {
    // ---------- 创建 ----------
    let mut scores = HashMap::new();
    let mut prebuilt = HashMap::from([
        ("红队".to_string(), 10),
        ("蓝队".to_string(), 20),
    ]);
    
    // ---------- 增删改 ----------
    scores.insert(String::from("蓝队"), 10);
    scores.insert(String::from("红队"), 20);
    scores.insert(String::from("黄队"), 15);
    
    scores.remove("红队");  // 删除
    
    // ---------- 访问 ----------
    // get 返回 Option<&V>
    let score = scores.get("蓝队");
    match score {
        Some(s) => println!("蓝队得分: {}", s),
        None => println!("蓝队不在表中"),
    }
    
    // 如果键不存在，提供默认值
    let yellow_score = scores.get("黄队").copied().unwrap_or(0);
    
    // ---------- entry API（推荐！）----------
    // entry().or_insert()——存在则返回引用，不存在则插入默认值
    let text = "hello world hello";
    let mut word_count = HashMap::new();
    
    for word in text.split_whitespace() {
        let count = word_count.entry(word).or_insert(0);
        *count += 1;  // or_insert 返回 &mut V
    }
    println!("{:?}", word_count);  // {"hello": 2, "world": 1}
    
    // 更复杂的 entry 用法
    let map: HashMap<&str, Vec<i32>> = HashMap::new();
    // map.entry("key").or_insert_with(Vec::new)
    
    // ---------- 遍历 ----------
    for (key, value) in &scores {
        println!("{}: {}", key, value);
    }
    
    // ---------- HashMap vs BTreeMap ----------
    // HashMap: 无序，O(1) 访问，需要 Hash trait
    // BTreeMap: 有序（按键排序），O(log n) 访问，需要 Ord trait
    use std::collections::BTreeMap;
    let mut btree = BTreeMap::new();
    btree.insert("c", 3);
    btree.insert("a", 1);
    btree.insert("b", 2);
    // 遍历时按 key 排序：a, b, c
    for (k, v) in &btree {
        println!("{}: {}", k, v);
    }
}
```

**HashSet——集合（无重复值的容器）：**

```rust
use std::collections::HashSet;

fn main() {
    let mut set = HashSet::new();
    
    set.insert(1);
    set.insert(2);
    set.insert(3);
    set.insert(1);  // 重复插入，不会增加
    
    println!("{:?}", set);  // {1, 2, 3}
    println!("包含 2? {}", set.contains(&2));  // true
    
    // 集合运算
    let a: HashSet<i32> = [1, 2, 3, 4].iter().copied().collect();
    let b: HashSet<i32> = [3, 4, 5, 6].iter().copied().collect();
    
    // 并集
    let union: HashSet<_> = a.union(&b).copied().collect();
    println!("并集: {:?}", union);  // {1, 2, 3, 4, 5, 6}
    
    // 交集
    let intersection: HashSet<_> = a.intersection(&b).copied().collect();
    println!("交集: {:?}", intersection);  // {3, 4}
    
    // 差集
    let diff: HashSet<_> = a.difference(&b).copied().collect();
    println!("差集: {:?}", diff);  // {1, 2}
}
```

**String 类型——深入理解：**

```rust
fn main() {
    // ---------- 创建 ----------
    let mut s = String::new();
    let s2 = String::from("hello");
    let s3 = "world".to_string();
    let s4 = format!("{} {}", s2, s3);  // "hello world"
    
    // ---------- 追加和插入 ----------
    s.push_str("hello ");     // 追加字符串
    s.push('W');              // 追加字符
    s += "orld";              // += 运算符
    
    // ---------- 拼接（注意所有权！）----------
    let hello = String::from("Hello, ");
    let world = String::from("world!");
    // hello + &world：hello 被移动（所有权被 + 拿走），world 被引用
    let hello_world = hello + &world;
    // println!("{}", hello);  // 错误！hello 已被移动
    println!("{}", world);    // OK，world 还在
    
    // 推荐：format! 宏（不转移所有权）
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");
    let s = format!("{}-{}-{}", s1, s2, s3);  // 三个都保留
    println!("{}", s);  // "tic-tac-toe"
    
    // ---------- 切片和索引 ----------
    // String 不能通过索引访问！因为 UTF-8 编码
    // let c = s[0];  // 编译错误！
    
    // 原因：一个"字符"可能占 1-4 个字节
    let hello = "你好".to_string();
    println!("字节长度: {}", hello.len());  // 6（每个中文 3 字节）
    println!("字符数: {}", hello.chars().count());  // 2
    
    // 正确访问方式：
    // 1. 遍历字符
    for c in "你好".chars() {
        println!("{}", c);
    }
    // 2. 遍历字节
    for b in "你好".bytes() {
        println!("{}", b);
    }
    // 3. 切片（按字节！小心在字符中间切）
    let hello = "hello世界";
    let slice = &hello[0..5];  // "hello"
    // let bad = &hello[0..6]; // panic！"世"占 3 字节，5-6 切到了字符中间
    
    // ---------- 常用方法 ----------
    let text = "  Hello, World!  ";
    println!("trim: '{}'", text.trim());      // "Hello, World!"
    println!("lower: {}", text.to_lowercase());// "  hello, world!  "
    println!("replace: {}", text.replace("World", "Rust"));
    
    // 分割
    let parts: Vec<&str> = "apple,banana,cherry".split(',').collect();
    println!("{:?}", parts);  // ["apple", "banana", "cherry"]
    
    // 判断
    let s = "rust";
    println!("starts with 'r'? {}", s.starts_with('r'));
    println!("contains 'us'? {}", s.contains("us"));
    
    // ---------- 其他集合类型 ----------
    // VecDeque：双端队列
    use std::collections::VecDeque;
    let mut deque = VecDeque::new();
    deque.push_back(1);    // 尾部添加
    deque.push_front(0);   // 头部添加
    let front = deque.pop_front();  // 弹出头部
    let back = deque.pop_back();    // 弹出尾部
    
    // LinkedList：双向链表（很少用，性能不如 VecDeque）
    // BinaryHeap：优先队列（最大堆）
    use std::collections::BinaryHeap;
    let mut heap = BinaryHeap::new();
    heap.push(3);
    heap.push(1);
    heap.push(5);
    println!("最大: {}", heap.peek().unwrap());  // 5
    println!("弹出最大: {}", heap.pop().unwrap()); // 5
}
```

**关键点说明：**

| 概念 | 关键点 |
|------|--------|
| `Result<T, E>` | 用 `?` 传播错误；用 `match` 处理；用 `.map()` 转换 |
| `panic!` | 不可恢复错误；可用 `RUST_BACKTRACE=1` 查看栈跟踪 |
| 自定义错误 | 实现 `Display` + `Debug`；可用 `thiserror` crate 简化 |
| `Vec<T>` | `vec![]` 宏；`.push()`/`.pop()` O(1) 平摊；`.get()` 安全访问 |
| `HashMap<K,V>` | `.entry().or_insert()` 模式；注意所有权的默认行为 |
| `String` | UTF-8 编码；不能索引；`len()` 是字节长度 |
| `?` 运算符 | 在 `Result` 和 `Option` 上都可以用（Rust 1.22+） |
| `anyhow` crate | 简化错误处理（`anyhow::Result`、`bail!`、`ensure!`） |
| `thiserror` crate | 简化自定义错误类型的 derive 宏 |
